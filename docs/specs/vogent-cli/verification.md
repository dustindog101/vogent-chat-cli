# Independent verification

Verification against baseline `0ba82421bb1ba177d3e81e184c38c388d639987c` used the real CLI process and local HTTP/WebSocket fixtures. The fixtures record provider requests, chat creations, submitted turns, saved readbacks, and scoped appointment GETs. They make no external provider calls. This verification did not deploy code or change provider configuration.

The latest run of `node --test vogent/test/independent-process.test.mjs` passed 8/8. These subprocess checks cover a three-turn synthetic booking, exact saved offer/choice/confirmation ordering, exact appointment-row attribution, assistant wording without caller consent, contradictory caller consent, config and inspect JSON redaction, profile/preflight command parsing, historical dial/current-chat provenance, pre-create config drift, and env-file setup from a temporary working directory. The process fixture caught two defects: a default empty CLI object overriding the scenario's declared `inputs.callAgentInput`, and raw function header/body values in JSON inspection. Both were fixed and the independent process checks then passed.

An earlier `node --test vogent/test/*.mjs` run completed 44/44 before the JSON inspection fix and the final independent-test additions. It is historical evidence only, not the final all-suite result. Rerun all suites with `node --test vogent/test/*.mjs` after the implementation freeze; local fixture servers bind to `127.0.0.1`, so the environment may require the local-loopback test permission.

## Evidence boundaries

Local tests establish CLI behavior against controlled provider shapes. They do not establish text-chat tool support for a particular production agent, endpoint receipt, full provider trace population, prompt-version pinning, or voice/audio behavior. Read-only schema and saved-chat evidence is documented in [trace verification](trace-verification.json), [diagnostics evidence](diagnostics-evidence.md), and [fixability findings](fixability.md). Any fresh staging contract result is recorded separately from these fixture checks.
